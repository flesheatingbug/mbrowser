How to export bookmarks from other browsers
  1. Vivaldi / Chrome / Edge / Brave: press Ctrl+Shift+O (bookmark manager), open the menu, choose Export bookmarks. Or just use the list above: they are read straight from the browser’s own file.
  2. Firefox: Ctrl+Shift+O (Library), Import and Backup → Export Bookmarks to HTML. The list above also finds Firefox’s automatic backups.
  3. Safari: File → Export → Bookmarks.

Checking the vault…

Choose the file you exported. CSV from Chrome, Vivaldi, Edge, Brave, Firefox, Bitwarden, LastPass, 1Password and KeePass works, and so does an unencrypted Bitwarden .json.

How to export passwords from other browsers and managers
  1. Vivaldi / Chrome / Edge / Brave: open vivaldi://password-manager (or chrome://password-manager/settings), Settings, Export passwords. Your operating system password is asked.
  2. Firefox: about:logins, the “…” menu, Export Logins…
  3. Bitwarden: web vault or app → Tools → Export vault, format .json or .csv (not “encrypted”).
  4. LastPass / 1Password / KeePassXC: use their CSV export.

Delete the exported file as soon as you have imported it. It holds your passwords in plain text.
